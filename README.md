# TASKLY
## INTORDUCTION.
The taskly is a  is a simple and clean todo-list task management web the is fully functional site where you can list your task easily.
## DESCRIPTION.
 The website is mainly build using HTML, CSS AND JS. This website focus on practicing html, css and js as well as working on real ideas.
 ## Features
 Some of the features and attraction of the page are:
1. **Create a task quickly**
2. **Mark tasks as completed**
3. **Completed tasks are crossed out**
4. **Remove task which are no longer needed**
5. **Task remains saved even after refreshing the page which is one of the major attraction**
6. **Simple and easy to use**
## procedure to use taskly
1. **Enter your task**
2. **Select the task type**
3. **Click Add task or simply press "Enter" key**
4. **Mark the task as completed when finished**
5. **Delete tasks when they are completed**
